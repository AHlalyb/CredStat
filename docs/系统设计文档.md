# CredStat 凭证统计管理系统设计文档

## 1. 系统概述与架构设计

### 1.1 系统简介

CredStat（Credential Statistics System）是一个用于集中管理和统计各种系统、服务器、网络设备等凭证信息的综合管理系统。系统提供了凭证的录入、查询、修改、删除等功能，支持多种查询方式和数据导出，旨在提高凭证管理的安全性和效率。

### 1.2 系统架构

### 1.3 系统特点

- **前后端分离**：前端使用Vue 3框架，后端使用PHP RESTful API，实现了前后端的完全解耦
- **安全性高**：所有敏感信息（如密码）均经过加密存储，支持多种加密算法
- **响应式设计**：基于Element Plus组件库，支持各种设备的响应式访问
- **功能全面**：支持多种凭证类型的管理，包括系统登录信息、服务器凭证、网络设备凭证等
- **易于扩展**：模块化设计，便于后续功能扩展和定制
- **数据可视化**：提供直观的数据统计和查询功能

## 2. 核心功能模块说明

### 2.1 系统登录与权限管理

- **功能描述**：实现用户登录、注销、权限验证等功能
- **核心流程**：用户输入用户名密码 → 后端验证 → 生成会话 → 前端存储登录状态
- **技术实现**：基于SessionStorage的登录状态管理，支持自动过期

### 2.2 系统登录信息管理

- **功能描述**：管理各种信息系统的登录凭证
- **支持的登录类型**：Web登录、SSH登录、数据库登录等
- **主要功能**：录入、查询、修改、删除系统登录信息

### 2.3 服务器凭证管理

- **功能描述**：管理服务器的登录凭证信息
- **支持的服务器类型**：Linux服务器、Windows服务器等
- **主要功能**：服务器信息录入、凭证管理、状态监控

### 2.4 网络设备凭证管理

- **功能描述**：管理网络设备的登录凭证信息
- **支持的设备类型**：交换机、路由器、防火墙等
- **主要功能**：设备信息录入、凭证管理、SNMP配置

### 2.5 宿主机集群管理

- **功能描述**：管理宿主机集群及其物理机器信息
- **主要功能**：集群信息录入、物理机管理、集群关系维护

### 2.6 物理服务器管理

- **功能描述**：管理物理服务器的详细信息
- **主要功能**：服务器信息录入、硬件配置管理、带外管理

### 2.6.1 物理服务器信息录入流程

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  用户进入物理    │────▶│  填写服务器基础  │────▶│  添加硬件配置    │
│  服务器录入页面  │     │  信息           │     │  信息           │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                   │
                                   ▼
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  上传现场照片   │────▶│  点击保存按钮    │────▶│  前端验证表单    │
│  （可选）       │     │                │     │  数据           │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                   │
                                   ▼
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  发送保存请求    │────▶│  后端处理数据    │────▶│  保存到数据库    │
│  到后端API      │     │  并加密敏感信息  │     │                │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                   │
                                   ▼
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  返回保存结果    │────▶│  前端显示结果    │────▶│  重置表单状态    │
│  到前端         │     │  提示           │     │                │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

物理服务器信息录入功能涵盖了完整的服务器信息收集过程，包括：
1. 基础信息：机房位置、机柜编号、U位、厂商型号、序列号等
2. 管理信息：BMC地址、账号密码等带外管理信息
3. 日期信息：采购日期、维保截止日期
4. 硬件配置信息：硬盘、网卡、HBA卡、设备连线等详细配置
5. 现场图片：支持上传服务器现场照片作为辅助信息
### 2.7 域名及证书管理

- **功能描述**：管理域名信息及其SSL证书
- **主要功能**：域名信息录入、证书管理、过期提醒

### 2.8 信息查询与统计

- **功能描述**：提供多种查询方式和统计功能
- **查询方式**：关键词查询、多条件组合查询、全类别查询
- **数据导出**：支持Excel、PDF等格式的数据导出

### 2.9 基础对象设置

- **功能描述**：管理系统中的基础对象类型
- **主要功能**：对象类型定义、属性配置、关系管理

| TINYINT | 小整数类型，用于存储布尔值或状态标志 | 1（启用）, 0（禁用） |

#### 4.3.2 状态码定义

| 状态码 | 描述 | 应用场景 |
|-------|------|---------|
| 1 | 启用/激活 | 用户状态、凭证状态 |
| 0 | 禁用/停用 | 用户状态、凭证状态 |

## 8. 系统安全性设计

### 8.1 数据安全

- **数据加密**：所有敏感信息（如密码）均使用SecurityUtils类进行加密存储
- **传输安全**：建议在生产环境中使用HTTPS协议，确保数据传输的安全性
- **访问控制**：实现了基于角色的访问控制，不同用户拥有不同的操作权限

### 8.2 应用安全

- **输入验证**：所有用户输入均经过严格的验证，防止SQL注入、XSS等攻击
- **会话管理**：使用SessionStorage存储登录状态，关闭浏览器后自动失效
- **防止CSRF攻击**：实现了CSRF令牌验证机制

### 8.3 数据库安全

- **最小权限原则**：数据库用户仅拥有必要的操作权限
- **定期备份**：建议定期备份数据库，防止数据丢失
- **日志记录**：记录所有数据库操作日志，便于审计和故障排查
