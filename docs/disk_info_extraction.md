# Linux磁盘信息提取需求文档 
 
 ## 1. 需求概述 
 开发一个Linux磁盘信息提取工具，该工具能够从`df -h`和`blkid`命令的输出中提取特定磁盘信息，并排除系统默认挂载项。提取结果需满足指定格式要求，用于后续表单数据录入。 
 
 ## 2. 数据提取要求 
 
 ### 2.1 `df -h`命令输出提取 
 从`df -h`命令的输出结果中提取以下列信息： 
 - 第一列：作为"设备名称"的输入值 
 - 第二列：作为"容量"的输入值 
 - 第三列：作为"已使用空间"的输入值 
 - 第六列：作为"挂载点"的输入值 
 
 ### 2.2 `blkid`命令输出提取 
 从`blkid`命令的输出结果中提取： 
 - TYPE=后面的信息：作为"文件系统类型"的输入值 
 
 ### 2.3 排除系统默认挂载项 
 工具需排除Linux系统默认的以下挂载信息： 
 - tmpfs类型的文件系统 
 - devtmpfs类型的文件系统 
 - overlay类型的文件系统 
 - /run/user/*路径的挂载点 
 - /sys/fs/cgroup路径的挂载点 
 
 ## 3. 实现要求 
 1. 确保提取的数据准确对应，设备名称与文件系统类型需正确关联 
 2. 处理命令输出时需忽略标题行和无关信息行 
 3. 确保中文显示正常，无乱码问题 
 4. 提取过程不应修改原始系统配置或文件 
 
 ## 4. 输出要求 
 1. 提取结果需以结构化格式呈现，清晰展示设备名称、容量、已使用空间、挂载点和文件系统类型的对应关系 
 2. 排除项需完全不显示在最终结果中 
 3. 工具需提供明确的执行成功/失败反馈
