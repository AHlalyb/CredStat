# 服务器磁盘信息录入功能需求文档

## 1. 功能概述
在现有"服务器基本信息录入"页面的"备注信息"表单上方，新增服务器磁盘信息录入模块。该模块需根据操作系统类型动态展示不同的磁盘信息录入表单，并支持动态添加多个磁盘信息条目。同时，需实现基于截图粘贴或命令输出结果自动提取并填充磁盘信息的功能。

## 2. 详细功能需求

### 2.1 磁盘信息录入模块位置
- 在"服务器基本信息录入"页面中，"备注信息"表单上方新增"磁盘信息"录入区域
- 区域需包含清晰的标题"磁盘信息"及简要说明文字

### 2.2 操作系统类型判断逻辑
- 监听"操作系统类型"表单字段的输入值变化
- 实现不区分大小写的判断逻辑：
  - 若输入值包含"windows"（不区分大小写），则展示Windows磁盘信息录入表单
  - 若输入值不包含"windows"（不区分大小写），则默认展示Linux磁盘信息录入表单

### 2.3 Windows磁盘信息录入表单
每个磁盘条目需包含以下字段：
- **盘符号**（必填，文本输入框，如"C:"、"D:"）
- **容量**（必填，数字输入框，单位GB，支持两位小数）
- **已使用空间**（选填，数字输入框，单位GB，支持两位小数）
- **磁盘类型**（必填，下拉选择框：系统盘、数据盘、应用盘、备份盘）
- **文件系统格式**（必填，下拉选择框：NTFS、FAT32、exFAT）
- **磁盘信息备注**（选填，多行文本框，最多500字符）
- **操作按钮**：删除当前磁盘条目（每个条目独立按钮）

### 2.4 Linux磁盘信息录入表单
每个磁盘条目需包含以下字段：
- **设备名称**（必填，文本输入框，如"/dev/sda1"）
- **文件系统类型**（必填，下拉选择框：ext4、xfs、btrfs、tmpfs等常见Linux文件系统）
- **容量**（必填，数字输入框，单位GB，支持两位小数）
- **已使用空间**（选填，数字输入框，单位GB，支持两位小数）
- **挂载点**（必填，文本输入框，如"/"、"/home"）
- **挂载选项**（选填，文本输入框，如"defaults,noatime"）
- **磁盘用途**（必填，下拉选择框：系统分区、数据分区、应用分区、日志分区、交换分区）
- **磁盘信息备注**（选填，多行文本框，最多500字符）
- **操作按钮**：删除当前磁盘条目（每个条目独立按钮）

### 2.5 动态添加功能
- 提供明显的"添加磁盘"按钮（"+ 添加磁盘"）
- 点击按钮后，在当前磁盘条目下方新增一个空白磁盘信息录入条目
- 默认初始显示1个磁盘条目
- 最多支持添加10个磁盘条目
- 每个磁盘条目需有独立的删除按钮，删除时需二次确认

### 2.6 数据存储设计
- 磁盘信息需独立存储在数据库表中，建议表名为：server_cred_volu-info
- 表结构需包含：
  - 主键ID
  - 服务器ID（外键，关联服务器基本信息表）
  - 操作系统类型标识
  - 磁盘相关字段（根据操作系统类型存储对应字段）
  - 创建时间、更新时间、创建人、更新人

### 2.7 自动信息提取功能
#### 2.7.1 截图粘贴识别
- 提供"粘贴截图提取信息"按钮
- 支持用户粘贴Windows磁盘信息截图
- 自动识别并提取盘符号、容量等关键信息到表单中
- 识别结果需用户确认后才填充到表单

#### 2.7.2 Linux命令输出解析
- 提供"粘贴命令输出"文本区域
- 支持粘贴Linux系统下`df -h`命令输出结果
- 支持粘贴Linux系统下`blkid`命令输出结果
- 自动解析并提取设备名称、文件系统类型、容量、挂载点等信息
- 解析结果以列表形式展示，供用户选择需要导入的磁盘信息
- 用户确认后自动填充到表单中

## 3. 界面设计要求
- 磁盘信息区域需有清晰的边框或背景色区分
- 表单字段布局合理，标签与输入框对齐
- 动态添加/删除操作有明确的视觉反馈
- 操作系统类型切换时，表单切换需平滑过渡
- 整体风格需与现有页面保持一致
- 响应式设计，适配不同屏幕尺寸

## 4. 文档交付要求
- 产出"需求文档"和"功能设计文档"两份文档
- 文档格式为Markdown（.md）
- 文档存放路径：项目根目录下的docs/文件夹
- 文档需包含必要的截图或示意图（可使用占位符标注位置）
- 文档需包含字段说明、业务逻辑说明、数据结构说明
