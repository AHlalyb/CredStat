# 服务器磁盘信息录入功能设计文档

## 1. 功能概述
在现有"服务器基本信息录入"页面的"备注信息"表单上方，新增服务器磁盘信息录入模块。该模块根据操作系统类型动态展示不同的磁盘信息录入表单，并支持动态添加多个磁盘信息条目。同时，实现基于截图粘贴或命令输出结果自动提取并填充磁盘信息的功能。

## 2. 技术架构设计

### 2.1 前端技术栈
- Vue 3 + Element Plus
- JavaScript + HTML + CSS
- Canvas API（用于截图处理）
- 正则表达式（用于命令输出解析）

### 2.2 后端技术栈
- PHP + PDO（数据库操作）
- MySQL（数据存储）

### 2.3 数据流向
1. 用户在前端填写磁盘信息
2. 前端根据操作系统类型动态切换表单
3. 用户可选择手动填写或自动提取磁盘信息
4. 表单数据通过AJAX发送到后端
5. 后端验证数据并存储到数据库
6. 服务器基本信息与磁盘信息通过外键关联

## 3. 数据模型设计

### 3.1 数据库表结构

#### 3.1.1 服务器磁盘信息表（server_cred_volu_info）
```sql
CREATE TABLE `server_cred_volu_info` (
  `id` INT AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
  `server_cred_id` INT NOT NULL COMMENT '服务器ID，外键关联server_cred表',
  `os_type` ENUM('windows', 'linux') NOT NULL COMMENT '操作系统类型',
  
  -- Windows特有字段
  `windows_drive_letter` VARCHAR(10) DEFAULT NULL COMMENT 'Windows盘符号',
  `windows_disk_type` ENUM('system', 'data', 'application', 'backup') DEFAULT NULL COMMENT 'Windows磁盘类型',
  `windows_file_system` ENUM('ntfs', 'fat32', 'exfat') DEFAULT NULL COMMENT 'Windows文件系统格式',
  
  -- Linux特有字段
  `linux_device_name` VARCHAR(50) DEFAULT NULL COMMENT 'Linux设备名称',
  `linux_mount_point` VARCHAR(100) DEFAULT NULL COMMENT 'Linux挂载点',
  `linux_mount_options` VARCHAR(200) DEFAULT NULL COMMENT 'Linux挂载选项',
  `linux_disk_purpose` ENUM('system', 'data', 'application', 'log', 'swap') DEFAULT NULL COMMENT 'Linux磁盘用途',
  
  -- 公共字段
  `capacity_gb` DECIMAL(10,2) NOT NULL COMMENT '容量（GB）',
  `used_space_gb` DECIMAL(10,2) DEFAULT NULL COMMENT '已使用空间（GB）',
  `file_system_type` VARCHAR(50) DEFAULT NULL COMMENT '文件系统类型（通用）',
  `notes` TEXT COMMENT '磁盘信息备注（最多500字符）',
  
  -- 元数据字段
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `created_by` VARCHAR(100) NOT NULL COMMENT '创建人',
  `updated_by` VARCHAR(100) DEFAULT NULL COMMENT '更新人',
  
  -- 外键约束
  CONSTRAINT `fk_server_cred_volu_info_server` FOREIGN KEY (`server_cred_id`) REFERENCES `server_cred` (`id`) ON DELETE CASCADE ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='服务器磁盘信息表';
```

### 4.2 自动信息提取功能设计

#### 4.2.1 截图粘贴识别
```javascript
// 截图粘贴处理
document.addEventListener('paste', (event) => {
  const items = event.clipboardData.items;
  for (let i = 0; i < items.length; i++) {
    if (items[i].type.indexOf('image') !== -1) {
      const blob = items[i].getAsFile();
      const reader = new FileReader();
      reader.onload = (e) => {
        const img = new Image();
        img.onload = () => {
          // 使用Canvas处理图像
          const canvas = document.createElement('canvas');
          const ctx = canvas.getContext('2d');
          canvas.width = img.width;
          canvas.height = img.height;
          ctx.drawImage(img, 0, 0);
          
          // 此处可集成OCR库进行图像识别
          // 示例：使用Tesseract.js进行OCR识别
          Tesseract.recognize(
            canvas,
            'chi_sim+eng',
            {
              logger: info => console.log(info)
            }
          ).then(({ data: { text } }) => {
            // 解析识别结果
            const extractedDisks = this.parseWindowsDiskInfo(text);
            this.extractedDisks = extractedDisks;
          });
        };
        img.src = e.target.result;
      };
      reader.readAsDataURL(blob);
    }
  }
});

// Windows磁盘信息解析
parseWindowsDiskInfo(text) {
  // 使用正则表达式解析识别结果
  const driveRegex = /([A-Za-z]):\s+([\d.]+)\s+GB\s+([\d.]+)\s+GB/gi;
  const disks = [];
  let match;
  
  while ((match = driveRegex.exec(text)) !== null) {
    disks.push({
      driveLetter: `${match[1]}:`,
      capacityGb: parseFloat(match[2]),
      usedSpaceGb: parseFloat(match[3])
    });
  }
  
  return disks;
}
```

#### 4.2.2 Linux命令输出解析
```javascript
// 解析df -h命令输出
extractFromCommand() {
  if (!this.commandOutput) {
    this.$message.error('请输入命令输出');
    return;
  }
  
  const lines = this.commandOutput.split('\n');
  const disks = [];
  
  // 跳过表头
  for (let i = 1; i < lines.length; i++) {
    const line = lines[i].trim();
    if (!line) continue;
    
    // 解析df -h输出
    const dfRegex = /^([\/\w\-]+)\s+([\d.]+[GMK])\s+([\d.]+[GMK])\s+([\d.]+[GMK])\s+(\d+)%\s+([\/\w\-]+)$/;
    const match = dfRegex.exec(line);
    
    if (match) {
      const device = match[1];
      const size = this.convertToGB(match[2]);
      const used = this.convertToGB(match[3]);
      const mountPoint = match[6];
      
      disks.push({
        deviceName: device,
        capacityGb: size,
        usedSpaceGb: used,
        mountPoint: mountPoint
      });
    }
  }
  
  this.extractedDisks = disks;
}

// 单位转换（GB、MB、KB to GB）
convertToGB(sizeStr) {
  const size = parseFloat(sizeStr);
  const unit = sizeStr.slice(-1);
  
  switch (unit) {
    case 'G':
      return size;
    case 'M':
      return size / 1024;
    case 'K':
      return size / (1024 * 1024);
    default:
      return size;
  }
}
```

## 6. 自动信息提取算法设计

### 6.1 截图识别算法
1. **图像预处理**：
   - 灰度化处理
   - 二值化处理
   - 去噪处理
   - 图像增强

2. **OCR识别**：
   - 使用Tesseract.js或其他OCR库进行文字识别
   - 支持中英文混合识别

3. **信息提取**：
   - 使用正则表达式解析识别结果
   - 提取盘符号、容量、已使用空间等关键信息
   - 验证提取结果的准确性

### 6.2 命令输出解析算法

#### 6.2.1 df -h输出解析
1. **行分割**：按换行符分割命令输出
2. **表头跳过**：跳过第一行表头
3. **字段匹配**：使用正则表达式匹配每行的设备名称、容量、已使用空间、挂载点等字段
4. **单位转换**：将KB、MB转换为GB
5. **数据清洗**：过滤无效行和系统临时文件系统

#### 6.2.2 blkid输出解析
1. **行分割**：按换行符分割命令输出
