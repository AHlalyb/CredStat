# CredStat 凭证统计管理系统

## 项目简介

CredStat是一个综合性的凭证统计管理系统，用于集中管理企业内部各类系统、服务器、网络设备等的登录凭证和相关信息，提高IT资产管理效率和安全性。

## 主要功能

- 用户认证与管理
- 物理服务器信息录入与管理
- 服务器账号密码管理
- 网络设备登录信息管理
- 宿主机集群管理
- 域名及证书管理
- 统一信息查询

## 系统要求

### 服务器环境
- Web服务器：Apache 2.4+ 或 Nginx 1.16+
- PHP版本：7.4+
- MySQL版本：5.7+
- 内存：建议4GB以上
- 存储空间：根据实际数据量需求，建议50GB以上

### 前端环境
- Node.js版本：16+
- npm或yarn包管理器

## 安装与部署

### 前端部署
1. 克隆代码仓库
2. 安装依赖：`npm install`
3. 构建生产版本：`npm run build`
4. 将构建生成的`dist`目录下的文件部署到Web服务器

### 后端部署
1. 将PHP代码部署到Web服务器
2. 确保`app/config/`目录有写入权限（用于保存数据库配置）
3. 确保`uploads/`目录有写入权限（用于保存上传的图片）
4. 访问系统，通过设置页面配置数据库连接
5. 初始化数据库表结构

### 系统初始化
1. 创建管理员用户：执行`create_admin_user.php`脚本
2. 测试系统功能
3. 配置系统参数
